## Task

You will develop an intuitive project management application tailored to “vibe-coding” projects. The objective is to create a tool that allows developers to track project tasks over time, keeping track of important information and key milestones throughout the process. This should include the ability to note useful prompts and results. The interface should include a kanban board for the user to manage tasks.
